Balayer un fil au trackpad
Les balayages existent déjà sur l'iPhone, dans une List. Sur Mac, la file est une vue custom et n'y avait pas droit. iOS 27 ouvre swipeActions à n'importe quelle vue posée dans un swipeActionsContainer.
InboxListPane .swipeActionsContainer() row(conversation) .swipeActions(edge: .trailing) { archiver; rappel }
