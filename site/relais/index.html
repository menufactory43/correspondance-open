Poser un Relais

Le Relais est votre serveur : celui qui porte vos conversations Signal, WhatsApp, Instagram, Messenger, X et Slack. Il se pose depuis le Mac, en un clic. Ensuite, l'iPhone s'y connecte.

1. Sur le Mac

  • Téléchargez Correspondance pour Mac et ouvrez-la.
  • Le premier écran dit « Il manque un Relais ». Cliquez « Installer ici » : le Relais se pose sur ce Mac, ou suivez « Sur une machine à moi » pour le poser sur une petite machine qui reste allumée.
  • Dans Réglages › Comptes, liez vos réseaux : un QR code pour Signal et WhatsApp, une fenêtre de connexion pour les autres.
Télécharger pour Mac

2. Sur l'iPhone

  • Sur le Mac, Réglages › Relais affiche un code d'appairage et six mots de vérification.
  • Dans l'app iPhone, collez le code, vérifiez que les six mots sont les mêmes, et connectez-vous.
  • L'iPhone doit être sur le même réseau que le Relais : à la maison, ou par Tailscale de partout.
Pas encore de Mac sous la main ? L'app iPhone a un mode démonstration, accessible depuis l'écran de connexion, pour voir à quoi elle ressemble.
